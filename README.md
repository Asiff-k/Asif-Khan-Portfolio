# Asiful Hasan Khan · Portfolio

Personal portfolio built with Next.js 16, TypeScript and Tailwind CSS 4. Every page is generated at build time, so the site needs no backend, database or environment variables.

## Run it locally

Requires Node.js 20.9 or newer.

```bash
npm install
npm run dev      # http://localhost:3000
```

Before deploying, check that these pass:

```bash
npm run lint
npm run build
npm start        # serves the production build at http://localhost:3000
```

## Where things live

| What | File |
|---|---|
| Name, contact details, social links, menu | `src/content/site.ts` |
| Projects and case study text | `src/content/projects.ts` |
| Graphic design gallery | `src/content/gallery.ts` |
| Jobs, AI data projects, education, tools | `src/content/experience.ts` |
| AI Tools page | `src/content/tools.ts` |
| Colours, fonts and type scale | `src/app/globals.css` |
| Spring and gesture settings | `src/lib/motion.ts` |

To change text, edit the content files. The page layouts read from them.

## Images

Web-ready images are in `public/images`, with their sizes listed in `src/content/media.generated.ts`. Both are generated by `scripts/process-images.mjs` from the original artwork, which is not part of this repository.

To add or replace an image:

1. Add the entry to the list at the top of `scripts/process-images.mjs`.
2. Run `npm run images -- --template <folder with the Template artwork> --staging <folder with photos, ui and apps subfolders>`.
3. Use the new key (for example `graphics/my-poster`) in a content file.

The script never changes the source files. It strips metadata such as GPS location from every output.

## Deploy to Vercel

1. Push this folder to a new GitHub repository. Make `portfolio` the repository root, or set **Root Directory** to `portfolio` in Vercel.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Leave the defaults: Framework **Next.js**, Build Command `next build`, no environment variables.
4. Click **Deploy**.

Vercel sets `VERCEL_PROJECT_PRODUCTION_URL` automatically, and the sitemap, robots.txt and social preview links use it. To use your own domain, add it under **Project → Settings → Domains** and follow the DNS steps Vercel shows.
